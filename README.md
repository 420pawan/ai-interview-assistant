\# 🎯 AI Interview Preparation Platform



An AI-powered Interview Preparation Platform that helps users practice technical interviews with personalized AI-generated questions, resume-based interview sessions, and instant feedback using Google's Gemini AI.



\## 🚀 Live Demo



\- 🌐 Frontend: https://ai-interview-assistant-pawan11.vercel.app

\- ⚙️ Backend API: https://ai-interview-assistant-backend-2grc.onrender.com



\---



\## ✨ Features



\- 🔐 User Authentication (JWT + Cookies)

\- 📄 Resume Upload

\- 🤖 AI-generated Interview Questions (Google Gemini AI)

\- 💬 Interactive Interview Sessions

\- 📊 Personalized Feedback \& Evaluation

\- 👤 User Dashboard

\- ☁️ MongoDB Atlas Database

\- 🌐 Fully Responsive UI

\## 💻 Installation



\### Clone Repository



```bash

git clone https://github.com/420pawan/ai-interview-assistant.git

```



\### Backend



```bash

cd Backend

npm install

npm run dev

```



\### Frontend



```bash

cd Frontend

npm install

npm run dev

```
